# EcoSentinel — Main site

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build in dist/
```

Optional live sensor feed: copy `.env.example` to `.env` and set the `VITE_*` values.
`VITE_MAPS_APP_URL` points at the Maps app (default `http://localhost:5173/`).
